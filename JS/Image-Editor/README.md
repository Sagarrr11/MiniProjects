# Image Editor

A simple browser-based image editor built with **HTML, CSS, and JavaScript**. It uses the **Canvas API** to load images, apply real-time filters and presets, and download the edited result.

## Features

- Upload images from your device
- Adjust:
  - Brightness
  - Contrast
  - Saturation
  - Hue
  - Blur
  - Grayscale
  - Sepia
  - Invert
  - Opacity
- Multiple image presets
- Reset all adjustments
- Download the edited image
- Real-time filter preview
- Dynamic filter controls generated with JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Canvas API

## Getting Started

1. Clone the repository.
2. Open `index.html` in your browser.
3. Upload an image and start editing.

No installation or dependencies are required.
