# Kanban Board

A simple Kanban board built with HTML, CSS, and JavaScript. Tasks can be created, deleted, and moved between different workflow columns using drag and drop.

## Features

- Add new tasks with a title and description
- Move tasks between To-do, In Progress, and Done
- Delete tasks
- Display task counts for each column
- Persist tasks using Local Storage
- Restore tasks after refreshing the page
- Responsive and clean UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API

## What I Practiced

- DOM manipulation
- Event handling
- Drag and drop API
- Dynamic element creation
- Local Storage
- Functions and reusable logic
- Working with arrays and objects

## How to Run

1. Clone the repository.
2. Open `index.html` in your browser.

No installation or build tools are required.
