# macOS Inspired Portfolio

A macOS-inspired interactive portfolio built with React.

The project recreates a desktop-style experience where different sections of the portfolio open as interactive windows.

## Tech Stack

- React.js
- JavaScript
- SCSS
- React RND
- React Markdown
- React Syntax Highlighter

## Features

- macOS-inspired desktop UI
- Interactive Dock
- Draggable and resizable windows
- Terminal / CLI
- GitHub projects section
- Resume viewer
- Markdown notes
- Spotify window
- Live date and time
- Open and close application windows

## What I Practiced

- React components and props
- `useState` and `useEffect`
- Conditional rendering
- State management
- Event handling
- Component composition
- Rendering dynamic data
- Working with external libraries
- Markdown rendering and syntax highlighting
